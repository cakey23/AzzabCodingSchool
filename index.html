✦ Learning Tracks

Four tracks. One personalized path.

Each track is thoughtfully structured with age-appropriate tools, real projects, and clear milestones — designed to grow with your child.

Ages 4–7

Computer Foundations

The perfect starting point for young learners. Students build real comfort and confidence with technology — from navigating a computer to understanding how the digital world works. Lessons are patient, visual, and playful.

Skills Learned

  • Mouse & keyboard confidence
  • Typing fundamentals
  • Computer navigation
  • Digital creativity
  • Beginner logic thinking
  • Internet safety basics

Tools Used

  • Typing games & apps
  • Kid-friendly browsers
  • Digital drawing tools
  • Basic file management
  • Storytelling apps

Example Projects

  • Digital storybook
  • Typing speed challenge
  • Safe browsing exercise
  • Creative digital art piece
  • Folder organization system

Milestone Progression

Mouse & keyboard mastery
Typing speed benchmark
Navigation independence
Digital safety certification
Ages 7–10

Creative Coding

Where coding meets creativity. Students discover the joy of programming through Scratch — building animations, interactive stories, and their first real games. Core programming concepts are introduced through hands-on creating.

Skills Learned

  • Sequencing & loops
  • Events & conditionals
  • Animation principles
  • Game mechanics basics
  • Creative storytelling
  • Problem decomposition

Tools Used

  • Scratch (MIT)
  • Scratch Jr (entry)
  • Code.org activities
  • Simple game builders

Example Projects

  • Animated adventure story
  • Catch the falling stars game
  • Interactive greeting card
  • Maze escape challenge
  • Custom music visualizer

Milestone Progression

First Scratch animation
Interactive story complete
First playable game
Multi-scene project
Ages 10+

Web Design

Students step into real-world web development — learning the languages every website is built with. By the end, they'll have a personal website they built themselves, from scratch, with their own design choices.

Skills Learned

  • HTML structure & elements
  • CSS styling & layouts
  • Responsive design basics
  • Beginner JavaScript
  • UI design principles
  • Publishing a website

Tools Used

  • HTML & CSS
  • JavaScript (vanilla)
  • VS Code editor
  • GitHub Pages
  • Chrome DevTools

Example Projects

  • Personal portfolio page
  • Hobby or interest site
  • Interactive quiz page
  • Photo gallery layout
  • Animated landing page

Milestone Progression

First HTML page built
Styled multi-page site
JS interactivity added
Live published website
Ages 10+

Game Development

For students who love games and want to build them. Students learn programming through the lens of game design — creating mechanics, scripting behaviors, and shipping playable interactive projects they can share with friends and family.

Skills Learned

  • Game design fundamentals
  • Python scripting
  • Lua (Roblox Studio)
  • C# basics (Unity)
  • Game mechanics logic
  • Debugging & testing

Tools Used

  • Python / Pygame
  • Roblox Studio (Lua)
  • Unity basics (C#)
  • JavaScript + Canvas
  • Game design docs

Example Projects

  • Top-down adventure game
  • Roblox obstacle course
  • Platformer with levels
  • Puzzle game challenge
  • Multiplayer mini-game

Milestone Progression

First playable prototype
Scripted game mechanic
Multi-level game complete
Shareable published game

How I think about teaching

Parents are kept fully in the loop. Warm, detailed summaries after every session mean you're never wondering what happened.
